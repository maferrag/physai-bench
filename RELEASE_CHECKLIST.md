- [ ] Add model-specific frozen configurations, raw outputs, and provider metadata.
- [ ] Verify that no credentials, private endpoints, or sensitive mission data are present.
- [ ] Run validation, tests, and a clean-install smoke test.
- [ ] Replace the illustrative sample if a canonical public example is available.
- [ ] Add archival links for the dataset and code release.
- [ ] Change GitHub visibility from private to public only after author approval.
